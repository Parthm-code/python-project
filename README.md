Health Calculator

College Python Project

Project Overview

Health Calculator is a menu-driven Python program developed as a first-year college project. The program provides several basic health-related calculations and gives simple feedback based on the user's input.

The main purpose of this project is to demonstrate the practical use of fundamental Python programming concepts.

Features

The program includes the following features:

1. Water Intake Calculator
   
   - Takes water intake in liters.
   - Provides feedback based on the amount entered.

2. BMI Calculator
   
   - Takes weight and height as input.
   - Calculates BMI using the formula:
   
   BMI = Weight / Height²
   
   - Displays a basic BMI category.

3. Exercise Time Calculator
   
   - Takes daily exercise time in minutes.
   - Provides feedback based on the exercise duration.

4. Sleep Calculator
   
   - Takes daily sleep duration in hours.
   - Provides basic feedback about sleep duration.

5. Calorie Calculator
   
   - Takes weight, height, and age as input.
   - Allows the user to select an activity level.
   - Calculates an estimated daily calorie requirement using a BMR-based formula.

6. Health Report
   
   - Takes water intake, BMI-related measurements, exercise time, and sleep duration.
   - Generates a basic health score out of 100.

How to Run

1. Install Python 3 on your computer.
2. Save the program as:

health_calculator.py

3. Open the terminal or command prompt in the project folder.
4. Run:

python health_calculator.py
